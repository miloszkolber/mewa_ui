Checkbox

Lets someone select an independent option. A group of checkboxes works well when several choices may be selected at the same time.

Default

Basic checkbox with label.

<input class="checkbox" type="checkbox" id="terms">
<label for="terms">Accept terms and conditions</label>

With description

Checkbox with helper text.

You can enable or disable notifications at any time.

<div class="checkbox-item-block">
  <input class="checkbox" type="checkbox" id="notify">
  <div>
    <label for="notify">Enable notifications</label>
    <p class="checkbox-description">...</p>
  </div>
</div>

Disabled

<input class="checkbox" type="checkbox" disabled>
<input class="checkbox" type="checkbox" disabled checked>

Checked by default

<input class="checkbox" type="checkbox" id="option" checked>
<label for="option">Pre-checked option</label>

Indeterminate

Set via JavaScript: checkbox.indeterminate = true.

<input class="checkbox" type="checkbox" id="select-all">
<label for="select-all">Select all</label>

<script>
  document.getElementById('select-all').indeterminate = true;
</script>

Invalid

Shows destructive border via aria-invalid="true".

<input class="checkbox" type="checkbox" aria-invalid="true">
<label for="terms">Accept terms and conditions</label>

Select-all group

Optional coordination keeps a native select-all checkbox in sync with its items.

Select items to display on the desktop

Choose which items are visible.

<fieldset class="checkbox-group" data-checkbox-group aria-describedby="group-help group-status">
  <legend>Select items to display</legend>
  <p class="checkbox-description" id="group-help">Choose which items are visible.</p>
  <label class="checkbox-item checkbox-group-select-all" for="group-all">
    <input class="checkbox" data-checkbox-all id="group-all" type="checkbox" aria-controls="group-items">
    <span>Select all</span>
  </label>
  <div class="checkbox-group-items" data-checkbox-items id="group-items">
    <div class="checkbox-item">
      <input class="checkbox" data-checkbox-item id="item-1" name="items" type="checkbox" value="one" checked>
      <label for="item-1">Hard disks</label>
    </div>
    <div class="checkbox-item">
      <input class="checkbox" data-checkbox-item id="item-2" name="items" type="checkbox" value="two">
      <label for="item-2">External disks</label>
    </div>
  </div>
  <output class="checkbox-group-status" data-checkbox-status id="group-status" role="status" aria-live="polite"></output>
</fieldset>
