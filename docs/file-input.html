File input

A styled native file picker. Built on <input type="file"> with custom ::file-selector-button styling. The browser keeps file selection, keyboard activation, focus, and drag-and-drop behavior.

Default

Single file selection. Keep a real label and use the native input for keyboard and screen-reader access.

<label class="label" for="avatar">Picture</label>
<input class="file-input" type="file" id="avatar" name="picture">

Multiple files

<label class="label" for="documents">Documents</label>
<input class="file-input" type="file" id="documents" name="documents" multiple>

Accept filter

<label class="label" for="image">Image only</label>
<input class="file-input" type="file" id="image" name="image" accept="image/*">

Native behavior

The control submits selected files through the surrounding form and remains usable without JavaScript. File picker contents and platform drag-and-drop UI are browser-owned. Focus changes are immediate with no animation or transition.
