Sidebar

Provides persistent application navigation on larger screens and a focused navigation dialog on smaller screens. The desktop rail is 256px expanded and 48px collapsed. It can collapse when more room is needed for the current task, using a short transition between states.

Default

Flat icon-and-label links with a footer collapse button. Press ⌘B or Ctrl+B to toggle the desktop width. The footer button stays keyboard reachable in both expanded and collapsed states.
