Sidebar

A composable, themeable application sidebar with flat navigation, collapsible desktop width, a mobile dialog overlay, and a footer collapse control. Width and disclosure changes are immediate with no animation.

Default

Flat icon-and-label links with a footer collapse button. Press ⌘B or Ctrl+B to toggle the desktop width. The footer button stays keyboard reachable in both expanded and collapsed states.
