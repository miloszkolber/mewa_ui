Input OTP

Collects a short fixed-length verification code in separate, labelled native inputs. Typing advances through the cells, and a pasted code fills the remaining positions.

Six-digit code

A fieldset names the group. Each cell keeps its own position-specific accessible name.

Verification code

Enter the six-digit code sent to your phone.

Keyboard behavior

Arrow Left and Arrow Right move between cells. Backspace on an empty cell returns to the previous position. Tab keeps the normal form order.

Without JavaScript

All cells remain editable, validated, and submitted. The server receives the repeated field values in document order.
