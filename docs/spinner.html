Spinner

Signals that an indeterminate task is currently running. Use it beside a concise status message and remove it as soon as the result is available.

Default

Standard spinner at default size.

<svg class="spinner" role="status" aria-label="Loading" viewBox="0 0 24 24" fill="currentColor" xmlns="http://www.w3.org/2000/svg">
  <path d="M21 12a9 9 0 1 1-6.219-8.56"/>
</svg>

Sizes

Use the 12px, 16px, 20px, 24px, and 32px scale with xs, sm, md, lg, and xl.

<svg class="spinner" data-size="xs" viewBox="0 0 24 24" fill="currentColor" xmlns="http://www.w3.org/2000/svg">...</svg> <svg class="spinner" data-size="sm" viewBox="0 0 24 24" fill="currentColor" xmlns="http://www.w3.org/2000/svg">...</svg> <svg class="spinner" viewBox="0 0 24 24" fill="currentColor" xmlns="http://www.w3.org/2000/svg">...</svg> <svg class="spinner" data-size="md" viewBox="0 0 24 24" fill="currentColor" xmlns="http://www.w3.org/2000/svg">...</svg> <svg class="spinner" data-size="lg" viewBox="0 0 24 24" fill="currentColor" xmlns="http://www.w3.org/2000/svg">...</svg> <svg class="spinner" data-size="xl" viewBox="0 0 24 24" fill="currentColor" xmlns="http://www.w3.org/2000/svg">...</svg>

In button

Spinner inside a loading button. It inherits the button's text color.

<button type="button" class="btn" data-variant="default" disabled>
  <svg class="spinner" aria-hidden="true" viewBox="0 0 24 24" fill="currentColor" xmlns="http://www.w3.org/2000/svg">...</svg>
  Loading...
</button>
