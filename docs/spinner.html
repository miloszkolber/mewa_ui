Spinner

A loading indicator rendered as a spinning SVG arc. The rotation is the one sanctioned animation in the library. No JavaScript is used.

Default

Standard spinner at default size.

<svg class="spinner" role="status" aria-label="Loading" viewBox="0 0 24 24"
     fill="none" stroke="currentColor" stroke-width="2"
     stroke-linecap="round" stroke-linejoin="round">
  <path d="M21 12a9 9 0 1 1-6.219-8.56"/>
</svg>

Sizes

Same data-size scale as icons: default, medium (md), large (lg), and extra large (xl).

<svg class="spinner">...</svg> <svg class="spinner" data-size="md">...</svg> <svg class="spinner" data-size="lg">...</svg> <svg class="spinner" data-size="xl">...</svg>

In button

Spinner inside a loading button.

<button type="button" class="btn" data-variant="default" disabled>
  Loading...
</button>
