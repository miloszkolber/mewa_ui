Date picker

Provides a custom month view for choosing a date. Use it when the surrounding calendar context matters more than the browser's compact native picker.

Basic date picker

Interactive calendar with month navigation and date selection. Arrow keys move focus through the grid, and native button activation selects a day.

<div class="date-picker">
  <div class="date-picker-header">

            aria-label="Previous month">
      <svg aria-hidden="true">...chevron left...</svg>
    </button>
    <span class="date-picker-heading" aria-live="polite"></span>
    <button class="date-picker-nav" type="button" data-action="next-month"
            aria-label="Next month">
      <svg aria-hidden="true">...chevron right...</svg>
    </button>
  </div>
  <table class="date-picker-grid" role="grid"></table>
</div>
