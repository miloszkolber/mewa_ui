Alert dialog

Use Alert Dialog for an irreversible or high-impact confirmation. Escape closes the native modal. Focus starts on the least destructive action.

Destructive confirmation

Keep a clear cancellation path and restore focus after close.

Delete account?

This action permanently deletes the account.

 
<button class="btn" type="button" data-variant="outline"
        data-alert-dialog-trigger="delete-account" aria-haspopup="dialog">
  Delete account
</button>

<dialog class="alert-dialog" id="delete-account" role="alertdialog"
        aria-modal="true" aria-labelledby="delete-title"
        aria-describedby="delete-description">
  <div class="alert-dialog-content">
    <div class="alert-dialog-header">
      <h2 class="alert-dialog-title" id="delete-title">Delete account?</h2>
      <p class="alert-dialog-description" id="delete-description">
        This action permanently deletes the account.
      </p>
    </div>
    <div class="alert-dialog-footer">
      <button class="btn" type="button" data-variant="outline"
              data-alert-dialog-close autofocus>Cancel</button>
      <button class="btn" type="button" data-variant="destructive"
              data-alert-dialog-close>Delete account</button>
    </div>
  </div>
</dialog>
