Text Field

A Kernel-aligned, native composition of a real <label>, real <input>, and optional description or error text. Zero JavaScript.

Default

The input remains the focusable and submitted form control.

We will never share your email address.

<div class="text-field">
  <label class="text-field-label" for="email">Email</label>
  <input class="text-field-input" id="email" name="email" type="email"
         aria-describedby="email-help">
  <p class="text-field-description" id="email-help">
    We will never share your email address.
  </p>
</div>

Required and invalid

Use native required and explicit aria-invalid state.

Enter your full name.

Readonly and disabled

You can select and copy this value.

Hidden label

The label is visually clipped, not removed from the accessibility tree.

Keyboard, events, and limitations

Tab and input-type-specific editing remain native. The input emits native focus, blur, input, change, and invalid events. Text Field emits no custom events and does not auto-generate IDs, wire descriptions, implement masks, or provide floating labels.

Standalone controls

Use .text-field-input for standalone controls, or wrap the control with .text-field when it has a label, description, or error message.

Use the standalone input class with native validation.

<label class="label" for="email">Email</label>
<input class="text-field-input" type="email" id="email" placeholder="you@example.com" aria-describedby="email-help">
<p class="text-field-description" id="email-help">Use the standalone input class with native validation.</p>

Standalone controls support native disabled, readonly, required, aria-invalid, file inputs, passwords, search fields, and inline buttons.
