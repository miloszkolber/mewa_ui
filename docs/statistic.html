Statistic

A numeric display for key metrics. Supports title, value, description, and trend indicators.

Component skill — components/statistic/statistic.md

Native basis

<div> containers displaying a numeric value with a label and optional trend indicator.

Web Platform APIs

<div>

Classes

.statistic .statistic-title .statistic-value .statistic-description .statistic-trend

Data attributes

• data-trend — values: up, down

Accessibility

• Use semantic text content — values are read inline

• Trends are conveyed by text, not color alone ("+12.5%")
