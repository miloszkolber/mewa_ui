Edge accent

Add the optional class beside app-shell on the body element to pin a flat diagonal hatch to both inline edges of the viewport. The accent is decorative, ignores pointer input, and stays omitted when the edges must stay clean.

Theme behavior

The theme follows the operating system until someone chooses a preference. The toggle stays hidden without JavaScript. Add the small pre-paint script before page content to prevent a flash of the wrong theme.
