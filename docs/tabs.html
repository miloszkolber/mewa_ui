Tabs

Organize content into switchable panels. Uses WAI-ARIA Tabs pattern with roving tabindex and arrow key navigation. Available in default and line variants. Tab selection and panel changes are immediate with no animation or transition.

Default variant

Default style with a --surface-secondary track. The active tab uses inverted surface and text roles, while idle tabs use readable secondary text. Focus remains on the active tab after keyboard navigation.

Vertical orientation

Set aria-orientation="vertical" on the tablist. CSS uses :has() to switch to a side-by-side layout automatically.
