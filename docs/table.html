Table

A responsive structural table component for displaying tabular data. Built on native <table> with captions, scoped headers, and optional footer rows. Use Data table for filtering, sorting, result status, and pagination enhancements.

Basic table

Standard table with a caption, scoped column headers, and body rows. Uses .badge for status and .avatar for user display. The semantic table remains usable at narrow widths inside its overflow container.
