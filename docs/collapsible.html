Collapsible

Reveals or hides one piece of supporting content. Use it when the closed label still gives enough context to decide whether opening the content is worthwhile.

Basic

Simple collapsible with a trigger and content.

Can I use this in my project?

Yes. Free to use for personal and commercial projects. No attribution required.

<details class="collapsible">
  <summary class="collapsible-trigger">
    <span>Can I use this?</span>
    <svg class="collapsible-chevron" viewBox="0 0 24 24" fill="currentColor" xmlns="http://www.w3.org/2000/svg">...</svg>
  </summary>
  <div class="collapsible-content">
    <p>Yes, it's free to use.</p>
  </div>
</details>

Open by default

Use the open attribute to start expanded.

Product details

This component uses the native <details> element with immediate expand/collapse state changes.

The browser handles the basic open and close behavior without additional JavaScript.

<details class="collapsible" open>
  <summary class="collapsible-trigger">...</summary>
  <div class="collapsible-content">...</div>
</details>
