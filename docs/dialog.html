Dialog

Modal window built on native <dialog> + showModal(). Focus management, Escape key, and backdrop are all browser-native. State changes are immediate with no animation or transition.

Form dialog

Dialog with form inputs. Click "Edit Profile" to open. Focus moves into the modal and returns to the trigger when it closes.

<button class="btn" data-variant="default"
        data-dialog-trigger="edit-dialog"
        aria-haspopup="dialog">
  Edit Profile
</button>

<dialog id="edit-dialog" class="dialog"
        role="dialog" aria-modal="true"
        aria-labelledby="edit-title">
  <div class="dialog-content">
    <div class="dialog-header">
      <h2 class="dialog-title" id="edit-title">Edit Profile</h2>
      <p class="dialog-description">Make changes to your profile here.</p>
    </div>
    <div class="dialog-body">
      <div style="display: flex; flex-direction: column; gap: var(--space-04)">

        </div>
        <div>
          <label class="label" for="username">Username</label>

</dialog>
