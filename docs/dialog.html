Dialog

Modal window built on native <dialog> + showModal(). Top-layer placement, inert background content, Escape key, and backdrop are browser-native. The module wraps keyboard focus between the first and last enabled controls. Control state feedback is fast and subtle; opening and closing remain immediate.

Form dialog

Dialog with form inputs. Click "Edit Profile" to open. Focus moves into the modal and returns to the trigger when it closes.

<button type="button" class="btn" data-variant="default"
        data-dialog-trigger="edit-dialog"
        aria-haspopup="dialog">
  Edit Profile
</button>

<dialog id="edit-dialog" class="dialog"
        role="dialog" aria-modal="true"
        aria-labelledby="edit-title">
  <div class="dialog-content">
    <div class="dialog-header">
      <h2 class="dialog-title" id="edit-title">Edit Profile</h2>
      <p class="dialog-description">Make changes to your profile here.</p>
    </div>
    <div class="dialog-body">
      <div style="display: flex; flex-direction: column; gap: var(--space-400)">
        <div>
          <label class="label" for="name">Name</label>
          <input class="text-field-input" id="name" type="text" value="Cody Lindley">
        </div>
        <div>
          <label class="label" for="username">Username</label>
          <input class="text-field-input" id="username" type="text" value="@codylindley">

    </div>
  </div>
</dialog>
