Dialog

Focuses attention on a short modal task without leaving the current page. Use it for work that benefits from interruption, not for ordinary content that fits in the page flow. Opening and closing use a short transition while focus and controls respond immediately.

Form dialog

Dialog with form inputs. Click "Edit Profile" to open. Focus moves into the modal and returns to the trigger when it closes.

        data-dialog-trigger="edit-dialog"
        aria-haspopup="dialog">
  Edit Profile
</button>

        role="dialog" aria-modal="true"
        aria-labelledby="edit-title">
  <div class="dialog-content">
    <div class="dialog-header">
      <h2 class="dialog-title" id="edit-title">Edit Profile</h2>
      <p class="dialog-description">Make changes to your profile here.</p>
