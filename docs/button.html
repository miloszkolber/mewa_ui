Button

Starts an action, submits a form, or presents a link with button styling. Choose the visual emphasis from the importance of the action, and keep navigation as a real link.

Variants

Choose a style that matches the action's importance. Default provides the strongest emphasis.

<button class="btn" type="button" data-variant="default">Default</button>
<button class="btn" type="button" data-variant="secondary">Secondary</button>
<button class="btn" type="button" data-variant="ghost">Ghost</button>
<button class="btn" type="button" data-variant="destructive">Destructive</button>

Sizes

Use the compact size in dense rows and the default size for ordinary actions. Icon-only buttons have matching square sizes.

<button class="btn" type="button" data-variant="secondary" data-size="sm">Small</button>
<button class="btn" type="button" data-variant="secondary">Default</button>

Icon

Use a square button for familiar icon-only actions, and provide an aria-label that names the action.

<button class="btn" type="button" data-variant="secondary" data-size="icon-sm"
        aria-label="Settings">
  <svg aria-hidden="true" width="14" height="14" viewBox="0 0 24 24" fill="currentColor" xmlns="http://www.w3.org/2000/svg">...</svg>
</button>

<button class="btn" type="button" data-variant="secondary" data-size="icon"
        aria-label="Settings">
  <svg aria-hidden="true" width="15" height="15" viewBox="0 0 24 24" fill="currentColor" xmlns="http://www.w3.org/2000/svg">...</svg>
</button>

With icon

Icons auto-size to 1rem. Place before or after the label.

<button class="btn" type="button" data-variant="default">
  <svg aria-hidden="true" width="15" height="15" viewBox="0 0 24 24" fill="currentColor" xmlns="http://www.w3.org/2000/svg">...</svg>
  Star
</button>

<button class="btn" type="button" data-variant="secondary">
  <svg aria-hidden="true" width="15" height="15" viewBox="0 0 24 24" fill="currentColor" xmlns="http://www.w3.org/2000/svg">...</svg>
  Download
</button>

Loading

Disabled button with a static status icon to indicate a pending action.

<button class="btn" type="button" data-variant="default" disabled>
  <svg aria-hidden="true" width="15" height="15" viewBox="0 0 24 24" fill="currentColor" xmlns="http://www.w3.org/2000/svg">
    <path d="M21 12a9 9 0 1 1-6.219-8.56"/>
  </svg>
  Loading...
</button>

Disabled

Disabled buttons remain visible but cannot be activated.

<button class="btn" type="button" data-variant="default" disabled>Default</button>
<button class="btn" type="button" data-variant="secondary" disabled>Secondary</button>
<button class="btn" type="button" data-variant="ghost" disabled>Ghost</button>
<button class="btn" type="button" data-variant="destructive" disabled>Destructive</button>

As link

Use <a> instead of <button> for navigation.

Navigate Learn more 
<a href="/page" class="btn" data-variant="default">Navigate</a>
<a href="/docs" class="btn" data-variant="secondary">Learn more</a>
