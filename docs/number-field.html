Number field

A numeric input with increment/decrement buttons. Built on <input type="number"> with custom stepper controls.

Default

The input stays on the left, with increment and decrement buttons side by side on the right. The input owns the visible focus ring, while both buttons remain keyboard-operable.

<div class="number-field">
  <input type="number" value="1" min="0" max="99" step="1">
  <button type="button" data-action="increment"
          aria-label="Increase quantity">+</button>
  <button type="button" data-action="decrement"
          aria-label="Decrease quantity">−</button>
</div>

With step

Use the native step attribute for decimal increments. The layout stays the same and the browser keeps range validation authoritative.

<label class="label" for="temperature">Temperature</label>
<div class="number-field">
  <input type="number" id="temperature" value="20.0"
         min="-40" max="60" step="0.5">
  <button type="button" data-action="increment"
          aria-label="Increase temperature">+</button>
  <button type="button" data-action="decrement"
          aria-label="Decrease temperature">−</button>
</div>
