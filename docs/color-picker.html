Color picker

Lets someone choose an opaque color with the platform picker or enter an exact hexadecimal value. The native color input remains the submitted field.

Color and hexadecimal value

The text field appears after its value can stay synchronized with the native picker.

Choose an opaque color.

Without JavaScript

The native color input stays visible, labelled, focusable, and submitted. The exact-value field stays hidden until synchronization is available.
