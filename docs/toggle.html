Toggle

A two-state button that can be either on or off. Uses <button> with aria-pressed. Common for toolbar formatting buttons (bold, italic) or feature toggles.

Component skill — components/toggle/toggle.md

Native basis

<button> element with aria-pressed. The browser provides click and keyboard

Web Platform APIs

smHeight: 2rem lgHeight: 2.5rem

Notes

• The toggle is just a button with aria-pressed — no custom elements needed.

• Icon-only toggles must have aria-label for screen readers.

• For toggle groups (e.g., text alignment), wrap in a container with role="group" and aria-label.

• The pressed state uses --accent / --accent-foreground to match the system’s conventions.

JavaScript view file

Single click handler toggles aria-pressed between "true" and "false".

// -- Toggle ---------------------------------------------------

function init() {
  document.querySelectorAll('.toggle:not([data-init]):not(.toggle-group .toggle)').forEach((toggle) => {
  toggle.dataset.init = '';
  toggle.addEventListener('click', () => {
    const pressed = toggle.getAttribute('aria-pressed') === 'true';
    toggle.setAttribute('aria-pressed', !pressed);
  });
});
}

init();
new MutationObserver(init).observe(document, { childList: true, subtree: true });
