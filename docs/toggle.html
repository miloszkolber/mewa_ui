Toggle

Turns one independent tool or display option on and off. The pressed state remains visible and available to assistive technology.

Default

Transparent at rest. Background appears on hover and when pressed.

← unpressed vs pressed 
<button type="button" class="toggle" aria-pressed="false"
        aria-label="Bookmark">
  <svg aria-hidden="true" width="16" height="16"
       viewBox="0 0 24 24" fill="none" stroke="currentColor"
       stroke-width="2" stroke-linecap="round"
       stroke-linejoin="round">
    <path d="m19 21-7-4-7 4V5a2 2 0 0 1 2-2h10a2 2 0 0 1 2 2v16z"/>
  </svg>
</button>

Outline

Visible border and secondary surface at rest.

<button type="button" class="toggle" data-variant="outline"
        aria-pressed="true" aria-label="Toggle italic">
  <svg aria-hidden="true" width="16" height="16" ...>...</svg>
</button>

<button type="button" class="toggle" data-variant="outline"
        aria-pressed="false" aria-label="Toggle bold">
  <svg aria-hidden="true" width="16" height="16" ...>...</svg>
</button>

With text

Icon and label together.

<button type="button" class="toggle" aria-pressed="false">
  <svg aria-hidden="true" width="16" height="16" ...>...</svg>
  Italic
</button>

Disabled

Disabled toggles remain visible but cannot be activated.

<button type="button" class="toggle" data-variant="outline"
        aria-pressed="false" disabled>Disabled</button>

<button type="button" class="toggle" data-variant="outline"
        aria-pressed="true" disabled>Disabled</button>
