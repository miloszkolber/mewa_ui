Button group

Keeps a small set of closely related actions together. Connected borders make the relationship visible without turning the group into a new control.

Horizontal

Default horizontal group with connected outline buttons.

<div class="btn-group" role="group" aria-label="Actions">
  <button type="button" class="btn" data-variant="secondary">Save</button>
  <button type="button" class="btn" data-variant="secondary">Edit</button>
  <button type="button" class="btn" data-variant="secondary">Delete</button>
</div>

With icons

Icon-only button group for compact toolbars.

<div class="btn-group" role="group" aria-label="Formatting">
  <button type="button" class="btn" data-variant="secondary" data-size="icon" aria-label="Bold">...</button>
  <button type="button" class="btn" data-variant="secondary" data-size="icon" aria-label="Italic">...</button>
  <button type="button" class="btn" data-variant="secondary" data-size="icon" aria-label="Underline">...</button>
</div>

Vertical

Stacked buttons with connected top/bottom borders.

<div class="btn-group" data-orientation="vertical" role="group" aria-label="Nav">
  <button type="button" class="btn" data-variant="secondary">Top</button>
  <button type="button" class="btn" data-variant="secondary">Middle</button>
  <button type="button" class="btn" data-variant="secondary">Bottom</button>
</div>

Separator

Use <hr role="separator"> to visually divide non-outline buttons. Outline buttons don't need separators since they have visible borders.

<div class="btn-group" role="group" aria-label="Clipboard">
  <button type="button" class="btn" data-variant="default">Copy</button>
  <hr role="separator">
  <button type="button" class="btn" data-variant="default">Paste</button>
</div>

Sizes

Control button size with data-size on individual buttons.

<!-- Small -->
<div class="btn-group" role="group" aria-label="Actions">
  <button type="button" class="btn" data-variant="secondary" data-size="sm">Save</button>
  <button type="button" class="btn" data-variant="secondary" data-size="sm">Edit</button>
</div>

Split button

A primary action button with a dropdown trigger.

<div class="btn-group" role="group" aria-label="Split action">
  <button type="button" class="btn" data-variant="secondary">Save</button>
  <hr role="separator">
  <button type="button" class="btn" data-variant="secondary" data-size="icon"
          aria-label="More options">
    <i class="ri-arrow-down-s-line"></i>
  </button>
</div>
