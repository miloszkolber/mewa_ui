Dropdown menu

Collects a compact set of actions behind one trigger. Arrow keys move through the available items, while Escape and outside interaction close the menu predictably.

Standard menu

Full-featured menu with icons, keyboard shortcuts, groups, separators, a disabled item, and a destructive action.
