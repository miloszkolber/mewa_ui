Icon

Uses the locally shipped Remix Icon set for familiar visual cues. Pair icons with visible text when possible, and give standalone meaningful icons an accessible alternative.

With buttons

Icons inside buttons inherit the button's color.

  <i class="ri-save-line"></i>
  Save
</button>

<button type="button" class="btn" data-variant="secondary" data-size="icon" aria-label="Settings">

</button>

Color

Icons inherit currentColor. Change color with text color utilities.

<i class="ri-checkbox-circle-line" data-size="lg" style="color: oklch(0.72 0.19 142)"></i>
<i class="ri-error-warning-line" data-size="lg" style="color: oklch(0.77 0.17 75)"></i>
<i class="ri-close-circle-line" data-size="lg" style="color: var(--text-negative)"></i>
<i class="ri-information-line" data-size="lg" style="color: var(--text-secondary)"></i>

Line and fill variants

Use the -line asset for the default outlined state and the -fill asset for selected or active states. Use data-icon-pair when a control must swap both assets in one stable slot.

line
fill 
<i class="ri-heart-line" data-size="lg" aria-hidden="true"></i>
<i class="ri-heart-fill" data-size="lg" aria-hidden="true"></i>

<button class="btn" type="button" data-variant="secondary" data-state="selected" aria-pressed="true">
  <span data-icon-pair aria-hidden="true">
    <i class="ri-heart-line" data-icon-variant="line"></i>
    <i class="ri-heart-fill" data-icon-variant="fill"></i>
  </span>
  Saved
</button>

Accessible icon

For standalone icons that convey meaning, use visually-hidden text or aria-label.

Phone number 
<!-- Preferred: visually-hidden text -->
<span style="display: inline-flex; align-items: center">
  <i class="ri-phone-line" aria-hidden="true"></i>
  <span class="sr-only">Phone number</span>
</span>

<!-- Alternative: aria-label -->
<i class="ri-error-warning-line" aria-label="Warning" role="img"></i>

Loading status

Use a static loader icon for loading indicators while animations are paused.

<i class="ri-loader-4-line" data-size="md"></i>

<button type="button" class="btn" data-variant="secondary" disabled>
  <i class="ri-loader-4-line"></i>
  Loading…
</button>

Switch the icon class when a control changes state. Keep the semantic color on the containing component.
