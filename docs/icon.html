Icon

The full Lucide icon set ships locally in src/icons/. Inline the matching SVG for the no-JavaScript path, or write <i data-lucide="name"> when a local loader such as js/site.js should inline it at page load. No CDN.

Inline SVG

Copy a local SVG from src/icons/ and keep decorative state explicit with aria-hidden="true".

<svg aria-hidden="true" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
  <path d="M15 21v-8a1 1 0 0 0-1-1h-4a1 1 0 0 0-1 1v8"></path>
  <path d="M3 10a2 2 0 0 1 .709-1.528l7-6a2 2 0 0 1 2.582 0l7 6A2 2 0 0 1 21 10v9a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2z"></path>
</svg>

default (16px)

With buttons

Icons inside buttons inherit the button's color.

<button class="btn" data-variant="default">
  <i data-lucide="save"></i>
  Save
</button>

<button class="btn" data-variant="outline" data-size="icon" aria-label="Settings">
  <i data-lucide="settings"></i>
</button>

Color

Icons inherit currentColor. Change color with text color utilities.

<i data-lucide="circle-check" data-size="lg" style="color: oklch(0.72 0.19 142)"></i>
<i data-lucide="triangle-alert" data-size="lg" style="color: oklch(0.77 0.17 75)"></i>
<i data-lucide="circle-x" data-size="lg" style="color: var(--text-negative)"></i>
<i data-lucide="info" data-size="lg" style="color: var(--text-secondary)"></i>

Stroke width

Adjust line thickness with the stroke-width attribute. Default is 2.

1.5
2 
<i data-lucide="heart" data-size="lg" stroke-width="1.5"></i>
<i data-lucide="heart" data-size="lg" stroke-width="2"></i>

Accessible icon

For standalone icons that convey meaning, use visually-hidden text or aria-label.

Phone number 
<!-- Preferred: visually-hidden text -->
<span style="display: inline-flex; align-items: center">
  <i data-lucide="phone" aria-hidden="true"></i>
  <span class="sr-only">Phone number</span>
</span>

<!-- Alternative: aria-label -->
<i data-lucide="triangle-alert" aria-label="Warning" role="img"></i>

Loading status

Use a static loader icon for loading indicators while animations are paused.

<i data-lucide="loader-circle" data-size="md"></i>

<button class="btn" data-variant="outline" disabled>
  <i data-lucide="loader-circle"></i>
  Loading…
</button>

Filled icons

Use the fill and stroke-width attributes for filled icon variants. Works well with simple shapes.

<i data-lucide="star" data-size="lg" fill="currentColor" stroke-width="0"></i>
<i data-lucide="heart" data-size="lg" fill="currentColor" stroke-width="0"></i>

<!-- Filled with stroke outline -->
<i data-lucide="star" data-size="lg" fill="currentColor" stroke-width="1.5"></i>
