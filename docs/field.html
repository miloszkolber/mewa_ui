Field

A native-first scaffold for labels, descriptions, errors, required states, and disabled controls. Field adds no JavaScript.

Default field

Use a labelled field and connect supporting text with aria-describedby.

We will use this address for account notices.

<div class="field">
  <label for="email">Email</label>
  <input class="text-field-input" id="email" name="email" type="email"
         aria-describedby="email-help">
  <p class="field-description" id="email-help">
    We will use this address for account notices.
  </p>
</div>

Required and invalid

Keep the native constraint and ARIA state on the input, with an explicit error association.

This username is already in use.

<div class="field" data-invalid>
  <label for="username">
    Username <span class="field-required" aria-hidden="true">*</span>
  </label>
  <input class="text-field-input" id="username" type="text" required
         aria-invalid="true" aria-describedby="username-error"
         aria-errormessage="username-error">
  <p class="field-error" id="username-error" role="alert">
    This username is already in use.
  </p>
</div>

Keyboard, events, and limitations

Field keeps native label focus, control-specific keyboard behavior, validation, and input, change, invalid, submit, and reset events. It emits no custom events and does not auto-generate IDs or ARIA links.
