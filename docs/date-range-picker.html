Date Range Picker

Collects a start and end date as two clearly labelled fields. The optional enhancement checks their order while preserving the browser's date controls and validation.

Default range

Tab between the independently labelled inputs. The browser owns each date picker and its date-segment keys.

Keyboard, events, and limitations

The native controls provide Tab order and browser-specific date segment editing. With the module loaded, date-range:change bubbles after a native change and date-range:invalid bubbles when chronological validity changes. Reversed values supplied by a server stay dormant until interaction, while the known invalid example preserves its server-rendered state. Native form reset restores the initial range and the module's event baseline. The browser calendar popup cannot be styled consistently, and this component does not add presets, a custom month grid, timezone handling, or animation.
