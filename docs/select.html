Select

Offers a familiar native list for choosing one or more fixed values. It is best for short lists that do not need search or custom option content.

Default

Native select with placeholder.

<select class="select">
  <option value="" disabled selected>Select a fruit</option>
  <option value="apple">Apple</option>
  ...
</select>

With groups

<select class="select">
  <optgroup label="Americas">
    <option>New York</option>
    ...
  </optgroup>
</select>

Disabled

<select class="select" disabled>...</select>
