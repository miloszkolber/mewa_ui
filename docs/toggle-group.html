Toggle group

Coordinates several related pressed buttons as a single-choice or multiple-choice set. Arrow-key navigation keeps the group efficient in toolbars and compact controls.

Single selection

Only one item can be active at a time. Use data-type="single".

<div class="toggle-group" role="group" aria-label="Alignment" data-type="single">
  <button type="button" class="toggle" aria-pressed="true"><i class="ri-align-item-left-line"></i></button>
  <button type="button" class="toggle" aria-pressed="false"><i class="ri-align-item-horizontal-center-line"></i></button>
  <button type="button" class="toggle" aria-pressed="false"><i class="ri-align-item-right-line"></i></button>
</div>

Multiple selection

Any combination of items can be active. Use data-type="multiple".

<div class="toggle-group" role="group" aria-label="Formatting" data-type="multiple">
  <button type="button" class="toggle" aria-pressed="true"><i class="ri-bold"></i></button>
  <button type="button" class="toggle" aria-pressed="false"><i class="ri-italic"></i></button>
  <button type="button" class="toggle" aria-pressed="false"><i class="ri-underline"></i></button>
</div>

Outline variant

Use data-variant="outline" for bordered toggles.

<div class="toggle-group" role="group" aria-label="View" data-type="single" data-variant="outline">
  <button type="button" class="toggle" aria-pressed="true"><i class="ri-list-unordered"></i></button>
  <button type="button" class="toggle" aria-pressed="false"><i class="ri-grid-line"></i></button>
  <button type="button" class="toggle" aria-pressed="false"><i class="ri-kanban-view"></i></button>
</div>

With spacing

Add data-spacing for gaps between individual toggles.

<div class="toggle-group" data-variant="outline" data-spacing data-type="single" ...>
  <button type="button" class="toggle" aria-pressed="true">...</button>
  <button type="button" class="toggle" aria-pressed="false">...</button>
  <button type="button" class="toggle" aria-pressed="false">...</button>
</div>

Vertical

Use data-orientation="vertical" for a vertical layout. Arrow Up/Down navigate.

<div class="toggle-group" role="group" aria-label="Alignment" data-type="single" data-orientation="vertical">
  <button type="button" class="toggle" aria-pressed="true">...</button>
  <button type="button" class="toggle" aria-pressed="false">...</button>
  <button type="button" class="toggle" aria-pressed="false">...</button>
</div>

With text

Toggle items can include text alongside icons.

<div class="toggle-group" role="group" aria-label="View mode" data-type="single" data-variant="outline">
  <button type="button" class="toggle" aria-pressed="true"><i class="ri-list-unordered"></i> List</button>
  <button type="button" class="toggle" aria-pressed="false"><i class="ri-grid-line"></i> Grid</button>
  <button type="button" class="toggle" aria-pressed="false"><i class="ri-layout-column-line"></i> Board</button>
</div>

Disabled

Add data-disabled to the group and disabled on each button.

<div class="toggle-group" role="group" aria-label="Formatting" data-type="multiple" data-disabled>
  <button type="button" class="toggle" aria-pressed="true" disabled>...</button>
  <button type="button" class="toggle" aria-pressed="false" disabled>...</button>
  <button type="button" class="toggle" aria-pressed="false" disabled>...</button>
</div>
