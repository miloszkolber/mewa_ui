Date field

Collects a date or local date and time with the browser's familiar input. It is the simplest choice when a custom calendar would not improve the task.

Date

Native date picker. The input remains the focus target and uses the shared :focus-visible state.

<label class="label" for="birthday">Birthday</label>
<input class="date-input" type="date" id="birthday" name="birthday">

Date and time

<label class="label" for="meeting">Meeting</label>
<input class="date-input" type="datetime-local" id="meeting" name="meeting">

With constraints

<label class="label" for="start">Start date</label>
<input class="date-input" type="date" id="start" name="start"
       min="2024-01-01" max="2026-12-31">

Native behavior

The browser or operating system owns the calendar popup, so its internal UI is not themed by this component. Date changes remain immediate while field state feedback is fast and subtle. Use the Date picker page for a custom month grid.
