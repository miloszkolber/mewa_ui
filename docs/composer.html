Composer

Collects a conversational message and keeps related actions close to it. Native form behavior remains available, while the optional module adds a predictable keyboard shortcut.

Message with actions

Command or Control plus Enter submits. The submit button keeps a normal native path.

⌘ or Ctrl + Enter 
<form class="composer" action="/messages" method="post" data-submit-on="mod-enter">
  <label class="composer-label" for="message">Message</label>
  <textarea class="composer-input" id="message" name="message" rows="2" required></textarea>
  <div class="composer-actions">
    <div class="composer-actions-trailing">
      <button class="btn composer-submit" type="submit" data-variant="default">Send</button>
    </div>
  </div>
</form>
