Layout

Intrinsic layout primitives: container, stack, grid, sidebar, center, and split. Built on CSS Grid and Flexbox — responsive by default, no breakpoints, no JavaScript.

Container

Constrains content to a centered max width (--container-max, default 64rem).

Centered, constrained content.

<div class="layout-container">
  <p>Constrained, centered content.</p>
</div>

Stack

Vertical rhythm for arbitrary content — children separated by the gap.

Profile

A short description of the account and its permissions.

<div class="layout-stack">
  <h2>Profile</h2>
  <p>A short description.</p>
  <button class="btn">Edit profile</button>
</div>

Grid

Intrinsically responsive columns (--min, default 15rem). Resize the window to watch them wrap.

Card 4

  <div>Card 1</div>
  <div>Card 2</div>

</div>

Sidebar

App-shell split. Content wraps below the sidebar when the container narrows — no media queries.

Main content

Takes the remaining space; wraps below the sidebar on narrow containers.

<div class="layout-sidebar">
  <nav>Sidebar links</nav>
  <main>Main content</main>
</div>

Center

Centers children on both axes. Give the element an explicit size.

Centered content

<div class="layout-center" style="min-block-size: 16rem">
  <p>Centered content</p>
</div>

Split

Opposite-end groups that wrap when space runs out. Useful for page headers.

Project settings

Manage preferences and permissions.

<div class="layout-split">
  <div>
    <h2>Title</h2>
    <p>Description</p>
  </div>
  <button class="btn">Action</button>
</div>

Gaps

Named gap values via data-gap, mapped to the --space-* scale.

data-gap="sm" — 0.75rem
data-gap="sm" — 0.75rem

  <p>First item</p>
  <p>Second item</p>
</div>
