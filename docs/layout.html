Layout

Intrinsic layout primitives: container, stack, grid, sidebar, center, and split. Built on CSS Grid and Flexbox — responsive by default, no breakpoints, no JavaScript.

Component skill — components/layout/layout.md

Native basis

CSS Grid and Flexbox layout primitives — no JavaScript or ARIA required.

Web Platform APIs

CSS Grid Flexbox min() fit-content() custom properties logical properties CSS nesting

Classes

.layout-container .layout-stack .layout-grid .layout-sidebar .layout-center .layout-split

Custom properties

--gapvar(--space-04)Gap between children — all primitives --min15remMinimum column width — grid --container-max64remMaximum width — container --sidebar-width14remMaximum sidebar width — sidebar

Data attributes

• data-gap — values: none, xs, sm, md, lg, xl (0 / 0.5 / 0.75 / 1 / 1.5 / 2.5rem)

ARIA

None required — purely visual layout containers. Semantics come from the elements inside.

Notes

• All primitives are intrinsic — they respond to container width, not breakpoints.

• Default gaps use the --space-* scale from base.css.

• .layout-sidebar requires exactly two children: first = sidebar, last = content.

• .layout-center needs an explicit size on the element to visibly center.

• Pure CSS — no JavaScript file exists for this component.

CSS view file

/* -- Layout component ---------------------------------------- */

@layer components {
  /* -- Gap scale --------------------------------------------- */
  :where(.layout-container, .layout-stack, .layout-grid, .layout-sidebar, .layout-center, .layout-split) {
    --gap: var(--space-04);
  }

  :where(.layout-container, .layout-stack, .layout-grid, .layout-sidebar, .layout-center, .layout-split)[data-gap="none"] { --gap: 0; }
  :where(.layout-container, .layout-stack, .layout-grid, .layout-sidebar, .layout-center, .layout-split)[data-gap="xs"]   { --gap: var(--space-02); }
  :where(.layout-container, .layout-stack, .layout-grid, .layout-sidebar, .layout-center, .layout-split)[data-gap="sm"]   { --gap: var(--space-03); }
  :where(.layout-container, .layout-stack, .layout-grid, .layout-sidebar, .layout-center, .layout-split)[data-gap="md"]   { --gap: var(--space-04); }
  :where(.layout-container, .layout-stack, .layout-grid, .layout-sidebar, .layout-center, .layout-split)[data-gap="lg"]   { --gap: var(--space-06); }
  :where(.layout-container, .layout-stack, .layout-grid, .layout-sidebar, .layout-center, .layout-split)[data-gap="xl"]   { --gap: var(--space-08); }

  /* -- Container --------------------------------------------- */
  .layout-container {
    width: min(100% - var(--space-08), var(--container-max, 64rem));
    margin-inline: auto;
    padding-inline: var(--space-04);
  }

  /* -- Stack ------------------------------------------------ */
  .layout-stack {
    display: flex;
    flex-direction: column;
    gap: var(--gap);
  }

  /* -- Grid ------------------------------------------------- */
  .layout-grid {
    display: grid;
    gap: var(--gap);
    grid-template-columns: repeat(auto-fit, minmax(min(100%, var(--min, 15rem)), 1fr));
  }

  /* -- Sidebar ---------------------------------------------- */
  .layout-sidebar {
    display: flex;
    flex-wrap: wrap;
    gap: var(--gap);

    & > :first-child {
      flex-basis: var(--sidebar-width, 14rem);
      flex-grow: 1;
    }

    & > :last-child {
      flex-basis: 0;
      flex-grow: 999;
      min-inline-size: 50%;
    }
  }

  /* -- Center ----------------------------------------------- */
  .layout-center {
    display: grid;
    place-content: center;
  }

  /* -- Split ------------------------------------------------ */
  .layout-split {
    display: flex;
    flex-wrap: wrap;
    align-items: center;
    justify-content: space-between;
    gap: var(--gap);
  }
}
