Command palette

A searchable command palette for quick actions. Built on native <dialog> with search filtering. Open with Cmd+K. Focus moves to the search input and returns to the trigger on close. State changes are immediate with no animation.

Default

Click the button or press ⌘K to open. Use Arrow keys to navigate, Enter to select, Escape to close.
