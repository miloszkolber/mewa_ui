Command palette

Offers a searchable list of application-wide commands in a modal surface. It is useful for experienced users who know what they want to do but not where the action lives. Opening and closing use a short transition, while search results update immediately.

Default

Click the button or press ⌘K to open. Use Arrow keys to navigate, Enter to select, Escape to close.
