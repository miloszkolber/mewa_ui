Keyboard and pointer behavior

Tab to the separator. Arrow keys move by one percentage point, Page Up and Page Down move by ten, and Home and End jump to the declared bounds. Pointer capture keeps a drag active after the pointer leaves the handle.

← / → Adjust width

Home / End Move to minimum or maximum

Page Up / Page Down Move by the page step

No-JavaScript fallback

The two panels are ordinary flow content and stay visible with the stylesheet alone. The handle is a static divider until the module is loaded.
