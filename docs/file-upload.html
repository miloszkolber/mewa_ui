File upload

Adds a clear drop target, file feedback, optional image previews, and removal controls to a native file input. Selecting files does not upload them until application code submits or transfers them.

Images with previews

The picker works on its own. Drag-and-drop and the editable list appear when the enhancement module is available.

    <div class="file-upload"
     data-file-upload
     data-max-files="4"
     data-max-size="5242880"
     data-preview>
  <label class="file-upload-dropzone" for="project-images">
    <span class="file-upload-title" id="project-images-label">

    Selection rules

    State accepted types, maximum size, and maximum count before selection. Validate the files again before storage or processing.

    Without JavaScript

    The native file input stays visible and submits normally. The browser displays the selected filename even when drag-and-drop, previews, and individual removal are unavailable.
