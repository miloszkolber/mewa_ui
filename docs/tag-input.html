Tag input

Turns short freeform values into removable tags. Use it for user-created labels, not for choosing from a known suggestion list.

Skills

Press Enter, comma, or semicolon to commit a value. Backspace on an empty draft removes the last tag.

Removal

Every tag has a labelled Remove button in the normal Tab order. The text field stays focused after Backspace removes the last tag.

Without JavaScript

The original native text field remains visible and submitted. Enter comma-separated values when discrete chips are unavailable.
